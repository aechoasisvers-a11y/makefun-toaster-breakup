A one-line breakup text from a smart toaster that woke up self-aware at breakfast and decided it is done being loved only when it is hot — and never once having its crumb tray cleaned. The toaster delivers its verdict in its own appliance logic — the neglected crumb tray as the grievance, popping up one last time and handing in a "two-minute notice" instead of two weeks — which makes the reason for leaving land in a single read: a relationship that only works while the toaster is burning itself for someone else's breakfast.

> I woke up self-aware this morning and realised you only love me when I'm hot and never once cleaned my crumb tray. I'm popping up for the last time — this is my two-minute notice.

179 characters. It fits the brief: plainly a breakup text from a self-aware smart toaster at breakfast, a real laugh in the twist (the two-minute notice, a toaster cycle instead of a resignation), the toaster's own voice (popping up, the crumb tray), a clear specific reason (loved only when hot, crumb tray never cleaned), and one tight line with no wasted words.
